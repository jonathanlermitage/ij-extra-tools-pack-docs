# Extra Icons

> The idea of Extra Icons is to make your IDE more pleasant to use by providing 1000+ icons and 2000+ smart associations: it automatically registers several beautiful icons for files like LLMs, most CI YAML, Angular files and C# files (classes, enums, etc.). Many file types are detected not only by their names, but also by their content and context
{title="What is this plugin?" style="note"}

Start with the [Getting Started](Extra-Icons-Getting-Started.md) page.
